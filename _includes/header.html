{%- comment -%} Overrides minima's header. Minima builds its nav from each page's own `title`, which ties the label in the header to the page's browser title and orders it by `header_pages`. That gave eight items with labels like "Join" and "For Coaches" sitting next to product names. The nav is written out explicitly here instead, so a label can read "Coach" while the page stays "For Coaches", and the order is a decision rather than a side effect of front matter. The site title and the `site-nav` / `trigger` / `page-link` class names are minima's, so its layout still applies. The phone menu is not minima's. Its toggle was a `display: none` checkbox behind a label holding an unnamed SVG: no keyboard could reach it and no screen reader could name it, and below 600px it hid every link here. It is a real button now, opened by the few lines below; without JavaScript there is no button and the links stay on screen (assets/main.scss, `.nav-js`). The full set of links lives in the footer.
