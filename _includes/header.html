{%- comment -%} Overrides minima's header. Minima builds its nav from each page's own `title`, which ties the label in the header to the page's browser title and orders it by `header_pages`. That gave eight items with labels like "Join" and "For Coaches" sitting next to product names. The nav is written out explicitly here instead, so a label can read "Coach" while the page stays "For Coaches", and the order is a decision rather than a side effect of front matter. Everything else — the site title, the checkbox menu toggle, the `site-nav` / `page-link` class names — is minima's, because minima's stylesheet is what makes the mobile menu work. The full set of links lives in the footer. This is the short list. {%- endcomment -%}
