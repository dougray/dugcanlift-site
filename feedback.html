bugs and ideas

Tell Me What's Wrong

Something broken, something confusing, something missing. This fills in an email and hands it to your mail app — nothing is sent from this page, and nothing about what you type touches a server. You see the message before it goes, and you press send.

One thing first. Don't paste a Send to Coach link or a Coach backup file into this form. Your whole log travels inside that link — everything you've eaten and lifted. Describe what happened instead. If the link itself is the problem, say so and we'll find a safer way to look at it.

If nothing opens

Some setups have no mail app wired up, and the button does nothing. In that case the address is dugcanlift@gmail.com — or copy the message and paste it wherever you read mail.

Or use GitHub

If you'd rather have a ticket you can follow, the templates are there and they ask the same questions. It's a public repository, so anything you write is public too — which is the reason the email above exists.

  • Report a bug on GitHub
  • Request a feature on GitHub

Either way it reaches the same person. There's one of me, so it may take a day, but every one of these gets read.
