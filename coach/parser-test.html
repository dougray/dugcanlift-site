Parser tests

Open this page to check the ingredient rules. No build step and no toolchain — the same reason the rest of Coach has none.

These cases mirror IngredientParserTests in the iOS build and IngredientParserTest in the Android one. All four implementations must give the same answer for the same line: a recipe written on one client reaches the others through the shared wire format, and a quantity that reads differently on one of them is a bug nobody would think to look for.
